# Kooka
_The Native Explorer_

Inspired by [**Files**](https://files.community/), **Kooka** is designed to capture the visual polish and advanced tooling of modern file managers at a fraction of the RAM footprint. Built as a dual-target monorepo, Kooka uses platform-native UI stacks (`windows-rs` on Windows, `gtk4-rs` on Linux) to guarantee maximum performance and ultra-low resource usage on both OSes.

> *"Wait, another file explorer?"*  
> I get it—a lot of custom file managers fall short on performance or UI polish. Thanks to low-level Rust and native Win32/GTK bindings, Kooka is built from the ground up to get both right this time.
